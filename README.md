StorageRoomDB is a program destined to adapt to a storage unit in a building, project, personal room, by allowing easy managing of electronic items. This database will allow users to log transactions done, like adding, removing items. Additionnally, each item will have trackable IDs. Notifications will be sent whenever a consumable item is low in stock.

WHAT IT DOES ATM:
-Item and transaction objects (constructors)
-SQLite JDBC Template

WHAT IS NOT AVAILABLE THUS FAR:
-Notifications are not yet part of the program
-GUI
-Web integration
